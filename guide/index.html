유의사항

시험 규정 (방송 공지)
  • 작품은 반드시 화지를 가로 규격으로 제작 (시험 시작 시 방송 공지)
  • 제시된 사물은 각각 1개씩만 표현 (2개 이상 그리지 않음)
  • 사전 배치된 정물대 위 정물은 손대거나 이동 금지 (단, 학생 시야에 보이는 사물을 표현하는 것은 가능)
  • 전동지우개 · 전동연필깎이 사용 금지
  • 화지 추가 요청 시 추가 지급
감독관
  • 감독관 휴대폰 무음 (시험실·복도 통화 금지)
  • 전자기기: 08:45 입실 시 부감독 수거(전원 OFF, 명렬표 스티커 · 추가 기기 공란 명렬표) → 09:00~09:10 복도 감독 인계 → 고사본부 보관 → 12:15 각 시험실 부감독에게 인계
  • 본인 확인(09:00~09:10): 정감독 비고란 ○ 정상 / 결시 / 확인×(학생증·여권 등 증빙 없음) · 화지 스티커는 종료 후 부착
  • 동명이인: 김지윤 2023·2024(제2시험실), 최하영 2083·2084(제6시험실) — 출신 중학교 확인
중간 퇴실·입실
  • 중간 퇴실 · 중간 입실 가능 (단, 다른 수험생에게 방해되지 않게)
  • 중간 퇴실 시: 감독이 화지 뒷면 우측 상단 수험표 부착·서명 → 복도 감독에게 인계 → 고사본부(미술과 연구실)에서 개인 전자기기 수령 안내
복도 감독
  • 08:40 집결 장소 → ~08:55 늦은 학생 시험실 안내(시험실 찾기 링크) → 09:00 배정 복도 → 09:10 전자기기 바구니 고사본부로 → 12:15 각 시험실 인계
  • 복도 감독: 학부모 등 외부인 발견 시 퇴실 요청 (시험장 건물 내 출입 금지 안내)
☔ 우천 시
  • 집결: 본동 중앙현관(1층) 예혼갤러리
  • 실기 시작 09:05 · 09:10 · 09:15 중 변경 가능 (당일 방송 통제, 이후 일정도 같은 만큼 늦춤)
  • 전임교사는 서두르지 말고 천천히 인솔, 도착 시간에 맞춰 유연하게 대처
Ⅵ

평가 및 집계

  1. 심사 종료 후 심사집계표에 이기, 집계, 확인 후 엑셀파일을 하경일 선생님께 전달
  2. 심사 집계표에는 최고점, 최하점을 제외한 평균점수 입력
  3. 개별 심사표(영역별 점수 합계), 심사 집계표(심사위원 점수 합계)는 점수 합계 필히 검토
  4. 점수 오기재 시 심사표 교체 / 부득이한 경우 두 줄 긋고 심사위원 날인

우천 시 · 중간 퇴실·입실 · 유의사항

☔ 우천 시
  • 집결 장소: 미술2동 주차장 → 본동 중앙현관(1층) 예혼갤러리
  • 실기 시작 09:05 · 09:10 · 09:15 중 변경 가능 (당일 방송 통제, 이후 일정도 같은 만큼 늦춤)
  • 전임교사는 서두르지 말고 천천히 인솔, 도착 시간에 맞춰 유연하게 대처
중간 퇴실·입실
  • 중간 퇴실 · 중간 입실 가능 (단, 다른 수험생에게 방해되지 않게)
  • 중간 퇴실 시: 감독이 화지 뒷면 우측 상단 수험표 부착·서명 → 복도 감독에게 인계 → 고사본부(미술과 연구실)에서 개인 전자기기 수령 안내
시험 규정 (방송 공지)
  • 작품은 반드시 화지를 가로 규격으로 제작 (시험 시작 시 방송 공지)
  • 제시된 사물은 각각 1개씩만 표현 (2개 이상 그리지 않음)
  • 사전 배치된 정물대 위 정물은 손대거나 이동 금지 (단, 학생 시야에 보이는 사물을 표현하는 것은 가능)
  • 전동지우개 · 전동연필깎이 사용 금지
  • 화지 추가 요청 시 추가 지급
감독관 유의사항
  • 감독관 휴대폰 무음 (시험실·복도 통화 금지)
  • 복도 감독: 학부모 등 외부인 발견 시 퇴실 요청 (시험장 건물 내 출입 금지 안내)
